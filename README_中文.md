核验包版本 1.0.0，整理日期 2026-10-05。仓库说明于2026-10-21更新，用于ENGINEERING Environment投稿；科学数据、核验脚本及参考结果未作修改。

本仓库对应论文《A Predictive Model for Settled-Water Turbidity under High-Turbidity Conditions Based on Dual-View Visual Fusion and Interface-Assisted Supervision》的Supplementary Code S1。

下载时选择“Code → Download ZIP”并解压。保留data、config、expected_results、scripts文件夹与run_verification.py的相对位置。复核投稿版本时，以论文标明的固定提交版本或发布版本为准。仓库已关闭自动换行转换，以保留原始脚本和数值文件的字节及哈希。

本包提供三类独立代码：**指标复算、实验组划分检查、注意力距离复算**，同时提供 **S01 图像归一化与 S02 训练增强的完整参数说明**。完整绘图程序不在本包中。

使用 Python 3.9 或更高版本，在当前文件夹打开终端后运行：

```text
python run_verification.py
```

无需安装任何第三方库，也不需要原项目、GPU、网络或模型权重。Windows 已安装 Python Launcher 时也可使用 `py -3 run_verification.py`。从其他目录运行时，给出脚本的完整路径即可；输入文件始终从脚本所在的包内读取。

默认结果保存在 `verification_output`，其中 `verification_summary.json` 是总核验报告。也可运行 `python run_verification.py --output-dir 自定输出目录`。成功时显示 PASS；数据、预期结果或文件完整性不符时返回失败，不会静默跳过。

## 可以核验的内容

- 8,985 个主线配对观测的分组与指标。训练 7,188、验证 599、测试 1,198；同一实验组不跨这三个集合。
- 正式测试结果中的 MAE 46.53 NTU、RMSE 130.71 NTU、MAPE 19.34%、R² 0.9249，以及包内列明的验证集/组别统计。
- 9 个侧视代表帧的坐标距离：总均值 0.116，低/中/高初始浊度组均值分别 0.101、0.072、0.175。
- RGB 像素归一化的计算算例，以及 RandAugment 对亮度/对比度各自至少选中一次的理论概率 27/196。

## 应如何理解结果

这些核验从**已保存的预测值、标签和坐标**开始，不重新训练模型或生成预测、注意力热图。因此，它们能检查数值计算及记录的一致性，不能独立证明这些输出由某个指定模型产生，也不支持对新图像作预测。

`target_ntu` 是原评估导出的参照标签，不能把每一帧的拟合/插值标签都称为该帧独立实测值。组间无交叉检查也不能替代所有类型的数据泄漏审计。

注意力距离的 9 个代表帧中，6 个属于测试集、3 个属于验证集。0.116 不是整个测试集的平均值。图像像素归一化 S01 与这一坐标距离归一化是两个不同指标，分别写在参数文件和距离核验脚本中。

总体 MAPE 的分母是 `target + 1`，逐点百分比误差上限为 1000%；当前代码口径的分组 MAPE 使用相同分母但不作该限幅。另外，历史验证/测试分组表中的 MAPE 可以用只除以 `target` 的公式复现，包内将这一口径作为单独诊断记录并核对，未将两者混称为同一指标。详细例子见方法说明。主线总体指标仍按 `target + 1` 核对。Python 对已导出的 NTU 数据汇总与原 float32 张量运算有微小差异，核验报告会显示与历史结果的差值及容差。

预处理参数来自已检查的正式实现：两视角和所有数据集使用相同 RGB 均值/标准差；训练增强按顺序组合，两视角各自随机抽样；验证/测试不作随机增强。本包只核查说明中的算术，不执行原始图像预处理，不声称重放了历史随机增强。

英文 README 和方法说明列出完整覆盖范围、数据字段及限制。哈希清单用于检查文件是否变动，不是科学来源认证。主体模型、训练、损失、权重、原始图像集合及软著文档均未纳入。
